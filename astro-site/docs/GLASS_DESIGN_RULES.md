# ガラス表現の正本（GLASS_DESIGN_RULES）

2026-10-05 MK 確定。サイトの見た目はガラスモーフィズムで統一する。
新しい部品を作るとき・既存の部品を直すときは、**ゼロから作らず、下の「見本」から派生させる**。

## 1. 原則（1 つだけ）

**色付きの薄い半透明 ＋ 同系色の枠 ＋ 同系色の文字**（必要なら同系色の柔らかい発光）。

- 枠と文字は必ず同じ色系統にする
- 塗りは「その色を薄く透かしたもの」。背景が透けて見えること

## 2. 見本（この作りに合わせる）

| 見本 | 場所 | 色 |
|---|---|---|
| メインバッジ（`.ag-pill.gold`） | 予想一覧の「メイン」 | 金 |
| お知らせ | マイページ | 金 |
| 本日の穴馬抽出ツール | 無料予想・マイページ | 金 |
| 会員限定のご案内 | マイページ | 金 |

## 3. 色の役割（新しい色系統を勝手に増やさない）

| 役割 | 色 | 例 |
|---|---|---|
| 会員の操作・取得状況 | 青 | 予想を取得する／今月の活用状況／取得済みの予想への導線 |

| 数字のアクセント | 取得数=青／利用日数=緑 | マイページ 今月の活用状況 |

## 4. やらないこと

- **不透明なベタ塗り**（ボタン・タブ・リンクを単色や濃いグラデーションで塗りつぶさない）
- **白の光沢・白っぽい塗りを重ねる**（乳白色に見える）
- **無彩色だけのガラス**（白・グレーの枠＋白の文字だけで色の役割が無い面）。冷たい金属のように見える（2026-10-05「ターミネーターっぽい」と指摘）
- 白抜き・グラデーション文字で数字を強調する（同系色の単色で強調する）
- 見本に無い新しい色系統を足す

## 5. 実装

- 共通 CSS: `astro-site/src/styles/acquisitionGlass.css`（`ag-` 接頭辞）
- 検証: `npm run test:acquisition`（`check:safety` に組込済み）がボタン・カード・マイページの取得状況の色の作りを確認する
- 見た目を変える依頼は、この正本の役割表のどの色かを先に決めてから作る
