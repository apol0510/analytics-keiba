> **このファイルは自動生成です。** 出所は `src/lib/marketing/filterDefinitions.js`。
> 手で編集せず、定義を直して `node astro-site/scripts/generate-filter-dictionary.mjs` を実行してください。

## 読み方

| 分類 | 意味 |
|---|---|
| 現在状態 | `state` |
| 履歴 | `history` |
| 追加条件 | `extra` |
| 操作可否 | `action` |

- **現在状態** … いまどうなっているか（母集団を作る）
- **履歴** … 過去に何があったか（現在状態とは別。混ぜない）
- **追加条件** … 現在状態をさらに絞る条件（単独では母集団を作らない）
- **操作可否** … いまその操作を実行できるか

- **API キー**: `contract`

| 表示名 | コード値 | 意味 |
|---|---|---|
| 有効 | `active` | 有料会員権限が現在有効です。 |

| 状態を判定できない旧データ | `unknown` | 旧形式の顧客データで、現在の契約状態を確実に判定できません。送信前に個別確認してください。 |
| 契約なし（無料会員） | `none` | 有料契約が確認できない無料会員です。 |

- **説明**: Premium Plus の販売対象として扱えるかを示します。会員プランとは別判定です。Premium Plus資格は検索条件です。選択しても販売資格は変更されません。

### オファーの状態（`mkOfferState`）

- **分類**: 現在状態
- **説明**: 顧客に発行済みの割引・購入オファーが、いまどうなっているかで絞り込みます。
- **API キー**: `offerState`
- **排他**: 1 顧客につき 1 区分だけ当たります
- **関係**: 現在利用できるオファーがある顧客を、残り期間でさらに絞り込めます。「残り期間」だけを選んでも、いま使えるオファーがある顧客だけが対象になります。

| 表示名 | コード値 | 意味 |
|---|---|---|
| 現在申込みに使えるオファーあり | `live` | 期限内で価格が設定された割引・購入オファーがあり、顧客がいま申込みに使えます。 |
| 申込み済み（オファー利用済み） | `redeemed` | 発行したオファーで既に申込みが行われています。いま使えるオファーはありません。 |
| 取り消したオファーのみ | `revoked` | 発行後に取り消したオファーだけが残っています。いま使えるオファーはありません。 |
| 期限切れのオファーのみ | `expired` | 発行したオファーの有効期限がすべて終了しています。 |
| オファーの発行なし | `none` | この顧客宛のオファーは 1 件も発行されていません。 |
| 状態を確認できない | `unknown` | オファー台帳を読み取れませんでした。「発行なし」とは限りません。 |

- **関係**: 現在利用できるオファーがある顧客を、残り期間でさらに絞り込めます。「残り期間」だけを選んでも、いま使えるオファーがある顧客だけが対象になります。

## Premium Plus 販売

### 販売状態（`fState`）

- **分類**: 現在状態
- **説明**: Premium Plus をいまこの顧客へ販売できるかの状態です。

| 表示名 | コード値 | 意味 |
|---|---|---|
| 保留（確認待ち） | `review` | 条件を満たすか確認が必要で、まだ販売対象にしていません。 |
| 販売できる | `eligible` | 段階公開の対象、または販売中です。 |
| すぐ販売できる（個別許可） | `immediate` | 管理者が個別に販売を許可しています。 |
| 販売対象外 | `blocked` | 販売しないと決めた顧客です。 |

### 資格の成立経路（`fRoute`）

- **分類**: 現在状態
- **説明**: Premium Plus の販売資格が、どの条件で成立したかを示します。

| 表示名 | コード値 | 意味 |
|---|---|---|
| 三連複の購入から | `sanrenpuku` | 三連複の買い切り購入により資格が成立しました。 |
| Premium 加入30日から | `premium_30d` | Premium 加入から 30 日経過して資格が成立しました。 |

### 候補の区分（`fKind`）

- **分類**: 現在状態
- **説明**: 販売資格が成立していない顧客を、その理由で分けて表示します。

| 表示名 | コード値 | 意味 |

### 販売する商品（`fUpsell`）

## 注意

- **コード値は API の許可値**です。表示名を変えてもコード値は変えないでください

- 定義に無い値は**言い換えません**（画面にはコード値がそのまま出ます）。
  新しい値を足したら、必ずここの定義にも追加してください。
