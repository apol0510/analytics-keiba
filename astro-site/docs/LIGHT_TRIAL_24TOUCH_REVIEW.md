### 読み方

- **touch 1〜6（体験中）**: 権利が有効であることを前提にした案内。`{{grantExpiry}}` で受信者ごとの
  終了日を差し込む。無料期間 30 日に現実的に収まるのはこの範囲。
- **touch 7〜24（体験終了後）**: 「期間は終わった」という事実の上に立つ案内。
  終了日の差し込みは**使わない**。無料会員として見られる範囲・実績・プランの案内で構成。

## 2. 停止条件（全 touch 共通）

| 条件 | 挙動 | 判定元 |
|---|---|---|
| 購入（有料プランが有効） | **即停止**（最優先） | `sequenceProgress` / `purchased` |
| 配信停止（unsubscribe） | 即停止 | `resolveSendability` / EmailBlacklist |
| ハードバウンス | 即停止 | EmailBlacklist |
| 苦情（complaint） | 即停止 | EmailBlacklist |
| provider suppression | 即停止 | SendGrid suppression 照会 |
| 対象外（付与取消 / 期限なし付与 / コホート外） | 即停止 | `grant_revoked` / `grant_lifetime` / `not_in_cohort` |
| 無料期間の終了 | **止めない**（終了後フェーズへ移行） | `grant_expired` → `requiresExpiredGrant` |
| **無反応が続く** | **止めない**（間隔を 2 倍に伸ばすだけ） | `stopAfterNoEngagement: null` |
| 24 通到達 | 終了 | `journeyModel.MAX_TOUCHES` |

短期の出しすぎ防止は据え置き（最小間隔 3 日 / 7 日 2 通 / 送信直前の横断頻度ガード）。

## 3. 最終校正の結果（touch 7〜24 / 初稿レビュー）

### 確認したこと

| 観点 | 結果 |

| 誇大表現・保証表現 | **なし**（`FORBIDDEN_PHRASES` 検査 + 目視。「必ず」「確実」「儲か」等ゼロ） |
