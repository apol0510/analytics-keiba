# 会員ランク（正本）

2026-10-05 MK 確定。マイページを「長く続けてもらえる居場所」にするための会員証。

## 1. 原則

- ランクは **会員歴（ご登録からの月数）だけ** で決める
- **取得数・購入額・的中では上げない**。たくさん買うほど得をする設計は賭け過ぎをあおるため採らない
- 特典はお金ではなく、居心地と先行体験（会員証の色・新機能の先行公開・Premium Plus の優先案内・長く続けた人への更新時のクーポン）。
  **実装済みの特典だけを画面に書く**。未実装の特典を約束しない（2026-10-05 時点で実装済み＝会員証の色とランク表示のみ）

## 2. ランク表

| ランク | 会員歴 | 色（GLASS_DESIGN_RULES.md） |
|---|---|---|
| レギュラー | ご登録から | 青 |
| ブロンズ | 3 か月〜 | 銅 |
| シルバー | 6 か月〜 | 銀 |
| ゴールド | 12 か月〜 | 金 |
| プラチナ | 24 か月〜 | 紫 |

マイページの会員証カードに「会員歴 N か月（YYYY年M月D日 ご登録）」と「次のランク ○○ まで あと N か月」（進み具合のバー）を出す。最上位はバーの代わりにお礼文。

## 3. 起点と対象

- 起点は Customers の **`登録日`**（`viewerProfile.registeredAt`）
- **`PaidAt` は使わない**。入金確認のたびに上書きされ、継続の起点にならない（2026-10-05 実測: 有料・有効 22 名のうち PaidAt は全員 3 か月未満、登録日は 22 名とも記入済み）
- そのため「課金を継続した月数」ではなく **「会員歴」** と表記する（無料期間を含む）。課金の継続月数を正確に出すには、更新履歴（Stripe の subscription 開始日等）を記録してからにする
- 対象は **有料の権利を今持っている会員だけ**（Light / Premium / Premium Sanrenpuku 等）。無料会員にはランクを出さない
- 月数は JST の暦で数える。月末起点（1/31 等）は月末で満了。未来日・読めない値はランクを出さない（推測しない）

## 4. 実装

- 判定: `src/lib/membership/memberRank.js`（純粋関数）
- 表示: `src/components/membership/MemberRankCard.astro`（色付きガラス・ランクで色が変わる）
- マイページ: `src/pages/dashboard.astro`（サーバー側で計算・本人の登録日だけ）
- 検証: `npm run test:membership`（`check:safety` に組込済み）
