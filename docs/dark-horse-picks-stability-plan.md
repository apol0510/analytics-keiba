## 6. 改善方針案（初期仮説）

穴馬抽出は、単なる人気薄ではなく、以下の複合条件にする。

- 人気またはオッズ面で妙味がある
- AI指数またはptが一定以上
- 印が完全無印ではない、または抑え・連下に近い評価がある
- 前走凡走でも、過去走・距離・展開・上がり・先行力などで巻き返し根拠がある
- featureScores / recentHorseHistories が使える場合は、それを補助指標にする
- 新馬・少走馬では過剰な断定を避ける

> 注: featureScores は現状 JRA のみ shared 由来で表示反映済み。南関 featureScores は admin/shared 側で生成検証中（slope18 維持確定・表示配線は別タスク）。穴馬抽出で featureScores を使う場合、**南関は未配線である前提**で fallback を設計する。

## 7. 表示コメント見直し案

## 8. UI / デザイン見直し観点

- カードの情報量が少なく、なぜ穴馬なのか分かりにくい
- AI評価の星だけでは判断基準が不明
- 「抽出指標」の各ラベルを見やすく整理する
- 前走着順だけでなく、指数・妙味・巻き返し根拠を分けて表示する
- 南関 / 中央JRAで表示フォーマットを統一する
- スマホ表示でカード間の余白・視認性を改善する
- 注意書きは残すが、過度に目立ちすぎないようにする

### UI方針の補足

現行デザインは大きく崩さない。
現在のダーク系・ガラスモーフィズム調の方向性は維持する。

改善は以下に限定する。

- 抽出指標をガラスモーフィズム調のバッジ / チップで表示する
- 「指数評価」「妙味度」「前走評価」などを視覚的に分離する
- コメントは短く、根拠が分かる形に整理する
- カード全体のデザイン刷新は行わない
- 背景、モーダル、カードの基本トーンは現状維持
- スマホ表示で見やすい余白と改行を整える程度に留める

現時点のUIは大きな問題なし。
主な改善対象は「なぜ穴馬なのか」が分かるコメント・指標表示である。

## 表示用語方針：「妙味度」は不採用

穴馬抽出ツールでは、今後「妙味度」という言葉は使用しない。

理由:
- 意味が曖昧で、配当期待や買い推奨のように見えやすい
- PR #58 で「妙味度あり」ラベルを削除済みであり、再採用すると表示方針がぶれる
- 実データに基づく根拠表示としては強すぎる

今後の表現候補:
- 好走圏
- 好走タイミング
- 好走条件
- 浮上余地
- 注目度
- 狙い目度

第一候補:
- 好走タイミング

「好走タイミング」は、勝利や的中を断定せず、条件が合えば好走する余地があるという意味に留められる。
そのため、星評価や補助ラベルを再設計する場合は、「妙味度」ではなく「好走タイミング」「注目度」などの表現を検討する。

禁止:
- 妙味度
- 妙味度あり
- 妙味度高い
- 配当妙味を断定する表現
- 買い推奨に見える強い文言

### 星評価再設計との関係（優先1）

優先1「星評価の意味再設計」では、以下の方針で進める。
- 星評価を「妙味度」として再定義しない
- 「妙味度」ラベルを復活させない
- 星評価を残す場合は、「好走タイミング」または「注目度」寄りの意味に整理する
- fallback が通常候補より強く見えないようにする
- 「AI評価」という名称も、必要なら「注目度」「好走タイミング」などへ弱める案を検討する

## 星評価再設計 第1段: fallback の星上限

Phase 2監査で、fallback 馬は score=50 固定のため常に★★★となり、通常抽出の★★馬より強く見えることが確認された。
fallback は「通常条件に該当馬がいない場合の救済枠」であり、通常候補より強く見せるべきではない。

第1段では、抽出ロジック本体や admin/shared の score は変更せず、AK表示側で fallback 馬の星評価を最大★★に抑える。

変更しないもの:
- admin dark-horse.mjs
- score計算
- gap計算
- lastFinish計算
- 抽出フィルタ
- AI指数
- 印
- 買い目
- shared JSON

第2段（別途）で検討:
- 表示用 ratingScore の新設（gap＋前走帯＋fallback減点、指数≤2位ペナルティの表示撤廃）

## 星評価再設計 第2段: 「AI評価」から「注目度」へ名称変更

Phase 2 / 第2段設計監査の結果、「AI評価」は決定論的な星表示に対して強すぎ、ユーザーが的中確率や馬の強さと誤読する可能性があると判断した。

第2段では、星表示の名称を「AI評価」から「注目度」へ変更する。
「注目度」は星との相性がよく、強さ・的中・買い推奨を断定しない。

今回は以下のみ実施:
- 「AI評価」→「注目度」への名称変更（表示は「👀 注目度」）

今回は実施しない:
- ratingScore 新設
- idx<=2 ペナルティ補正
- admin score 再設計
- pt / featureScores / 印の統合
- 「好走タイミング」を星ラベルとして使うこと

「好走タイミング」は、今後の条件コメントや補助表示の候補として保留する。

変更しないもの:
- getStarRating(horse) の計算式
- fallback 最大★★制限
- admin dark-horse.mjs
- score計算
- gap計算
- lastFinish計算
- 抽出フィルタ
- AI指数
- 印
- 買い目
- shared JSON
- KI

### 設計監査メモ（実データ）
- 抽出馬の gap は実データで概ね1〜3に収まり、星は「誠実な式」でも★★〜★★★の2〜3段階に自然集約。★★★★★はデータ的に乱発しない。
- 案B（再構成型）は全頭★★に潰れ差別化を失うため不採用。真の多段差別化は admin score 再設計（Phase 3・pt/featureScores 統合）が必要。
